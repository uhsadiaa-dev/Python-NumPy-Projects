📊 NumPy Project 1 – Student Mark Analysis
📌 Project Overview

Student Mark Analysis is a Python-based project that uses the NumPy library to analyze the academic performance of 30 students across 5 different subjects.

The project generates random marks for each student and provides several options to analyze student performance, calculate averages, identify toppers, assign grades, and check pass/fail status.

It is a beginner-friendly project designed to practice NumPy arrays, mathematical operations, conditional statements, and array manipulation.

🛠️ Technologies Used
Python – Programming language.
NumPy – For numerical calculations and data analysis.
📚 Subjects

The project analyzes marks in the following five subjects:

Mathematics
Physics
Chemistry
English
Computer Science

Total Students: 30

Marks Range: 35–100

✨ Features

The project provides a menu-driven system with 10 options:

Option	Feature
1	Calculate the average marks of each student.
2	Find the overall class topper.
3	Find the student with the lowest overall average.
4	Identify the highest and lowest-scoring subjects.
5	Find students who scored above 90 in all subjects.
6	Display individual subject grades for every student.
7	Calculate grades based on each student's average marks.
8	Find students who passed all five subjects.
9	Find students who failed in any subject.
10	Exit the program.

🧠 NumPy Concepts Practiced

This project helped me practice several important NumPy functions and concepts:

np.random.seed() – Generate reproducible random marks.
np.random.randint() – Generate random student marks.
np.sum() – Calculate total marks.
np.mean() – Calculate average marks.
np.argmax() – Find the highest value's index.
np.argmin() – Find the lowest value's index.
np.all() – Check whether all conditions are true.
np.any() – Check whether at least one condition is true.
np.where() – Find the indices of elements matching a condition.
np.select() – Assign grades based on multiple conditions.

💻 How It Works
The program generates random marks for 30 students across 5 subjects.
NumPy performs calculations to determine total and average marks.
The user selects an option from the menu.
The program analyzes the data and displays the requested results.
The menu continues running until the user chooses option 10 to exit.
