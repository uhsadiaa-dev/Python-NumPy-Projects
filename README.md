# 📊 Student Mark Analysis | NumPy Project 1

## 📌 About

A simple Python project using **NumPy** to analyze the marks of 30 students across 5 subjects.

It provides student performance analysis through a menu-driven program.

## 🛠️ Technologies Used

- Python
- NumPy

## ✨ Features

1. Calculate average marks of each student.
2. Find the class topper.
3. Find the lowest-performing student.
4. Identify the highest and lowest-scoring subjects.
5. Find students scoring above 90 in all subjects.
6. Calculate grades for each subject.
7. Calculate grades based on average marks.
8. Identify students who passed all subjects.
9. Identify students who failed any subject.
10. Find the topper of each subject.

## 🧠 NumPy Concepts Used

- `np.random.randint()`
- `np.sum()`
- `np.mean()`
- `np.argmax()`
- `np.argmin()`
- `np.all()`
- `np.any()`
- `np.where()`
- `np.select()`

## 🚀 How to Run

Install NumPy:

```bash
pip install numpy
```

Run the project:

```bash
python 1_student_mark_analysis.py
```
