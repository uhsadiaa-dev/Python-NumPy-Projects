📊 NumPy Project 1 – Student Mark Analysis
📌 About the Project

A beginner-friendly Python project using NumPy to analyze the marks of 30 students across 5 subjects.

The program generates random marks and provides different options to analyze student performance through a menu-driven system.

🛠️ Technologies Used
Python
NumPy
✨ Features
Calculate average marks of each student.
Find the class topper.
Find the student with the lowest average.
Identify the highest and lowest-scoring subjects.
Find students scoring above 90 in all subjects.
Display grades in each subject.
Calculate grades based on average marks.
Identify students who passed all subjects.
Identify students who failed in any subject.
